# Test Plan v1.0
**Purpose:** Ensure the SSTG system meets functional and non-functional requirements.

**Scope:** Covers all API endpoints, UI interactions, and system integrations.

**Test Tools:** Postman, Jest, GitHub Actions

**Testing Levels:**
1. Unit Testing (backend logic)
2. Integration Testing (API + DB)
3. System Testing (end-to-end)
4. Acceptance Testing (against SRS)

**Test Schedule:**  
Runs at the end of each sprint and before every demo.
