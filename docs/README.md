# 📚 Smart Studying Timetable Generator (SSTG) Documentation

This folder contains all project documentation for the **Software Analysis & Design** course.

**Structure**
- `01_SRS` – Requirements Specification
- `02_Analysis` – System Analysis (DFDs, ERD)
- `03_Design` – Architecture, UML Diagrams, Wireframes
- `04_Project-Plan` – Roles, Sprints, Risks
- `QA` – Quality Assurance Plans and Reports

All documents are versioned via Git commits and stored on GitHub + Google Drive for lecturer review.
